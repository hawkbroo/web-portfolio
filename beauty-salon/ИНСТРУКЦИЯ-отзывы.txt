================================================================================
ОТЗЫВЫ С МОДЕРАЦИЕЙ НА ПОЧТЕ (Google Таблица + Apps Script)
================================================================================
Цель: гость жмёт «Отправить» на сайте → заказчику письмо → «Подтвердить» →
отзыв сам появляется на сайте.

Важно про почту:
  Письмо уходит С того Google-аккаунта, который нажал «Развернуть / Разрешить».
  Поэтому таблицу создаёт исполнитель, а финальный деплой делает ЗАКАЗЧИК —
  тогда From = почта заказчика.

Файлы в проекте:
  - google-apps-script/Code.gs  — код для вставки в Apps Script
  - script.js                   — константа WEB_APP_URL (ссылка после деплоя)
  - ИНСТРУКЦИЯ-отзывы.txt       — этот файл


================================================================================
ЧАСТЬ 1. ИНСТРУКЦИЯ ДЛЯ ЗАКАЗЧИКА
================================================================================
Время: 10–15 минут один раз. Дальше — только открывать письма.

Что понадобится:
  - ваш обычный Gmail (тот, куда удобно получать отзывы);
  - компьютер или ноутбук;
  - ссылка на таблицу от исполнителя;
  - желательно 5 минут на звонке с исполнителем (он подскажет кнопки).


ШАГ 1. Войдите в свой Google
  1. Откройте https://mail.google.com или https://drive.google.com
  2. Войдите именно в ТОТ ящик, на который должны приходить отзывы.
  3. Если открыт чужой/рабочий аккаунт — смените на нужный.


ШАГ 2. Примите таблицу от исполнителя
  Вариант А — письмо Google «Вам предложили владение»:
    1. Откройте письмо.
    2. Нажмите «Принять» / «Accept».
    3. Откройте файл в Google Диске.

  Вариант Б — ссылка в мессенджере:
    1. Откройте ссылку на таблицу.
    2. Если Google просит доступ — запросите или дождитесь, пока исполнитель
       выдаст права / передаст владение.
    3. Убедитесь, что в углу таблицы видно, что вы можете редактировать
       (а лучше — что вы владелец).


ШАГ 3. Откройте редактор скриптов
  1. В открытой таблице сверху меню: «Расширения».
  2. Пункт: «Apps Script» (Редактор скриптов).
  3. Откроется новая вкладка с кодом. Ничего в коде менять не нужно,
     если исполнитель уже всё настроил.


ШАГ 4. Опубликуйте веб-приложение (самое важное — от ВАШЕГО имени)
  1. В правом верхнем углу синяя кнопка «Развернуть».
  2. Выберите «Новое развёртывание» (New deployment).
     Если уже было развёртывание исполнителя — всё равно сделайте НОВОЕ
     под своим аккаунтом или «Управление развёртываниями» → изменить /
     создать заново от вашего имени (как скажет исполнитель на созвоне).
  3. Нажмите шестерёнку «Выбрать тип» → «Веб-приложение».
  4. Заполните:
     - Описание: reviews
     - Запуск от имени: «От моего имени» (Me)  ← обязательно ВЫ
     - Кто имеет доступ: «Все» (Anyone)
  5. Нажмите «Развернуть».


ШАГ 5. Разрешите доступ (один раз)
  1. Google покажет окно проверки безопасности.
  2. Выберите свой аккаунт.
  3. Если написано «Приложение не подтверждено»:
       — «Дополнительные настройки» (Advanced)
       — «Перейти на страницу … (небезопасно)»
  4. Нажмите «Разрешить» на все пункты (таблица + отправка почты).
  5. Дождитесь окна с URL веб-приложения.


ШАГ 6. Отдайте ссылку исполнителю
  1. Скопируйте «URL веб-приложения»
     (начинается с https://script.google.com/macros/s/ ... /exec).
  2. Пришлите исполнителю в чат.
  3. Он вставит ссылку в сайт — без этого форма на сайте не заработает.


ШАГ 7. Проверка вместе с исполнителем
  1. Исполнитель (или вы) отправляет тестовый отзыв с сайта.
  2. Откройте почту — должно прийти письмо примерно:
       тема: «[Название сайта] Новый отзыв на модерацию»
       от: ваш Google / Apps Script от вашего аккаунта
  3. В письме кнопки «Подтвердить» и «Отклонить».
  4. Нажмите «Подтвердить» → откроется страница «Готово».
  5. Обновите страницу «Отзывы» на сайте — тестовый отзыв должен появиться.


ШАГ 8. Как пользоваться каждый день
  - Новые отзывы = новые письма.
  - «Подтвердить» = опубликовать на сайте.
  - «Отклонить» = не показывать.
  - В Google Таблицу заходить не обязательно.
  - Не удаляйте лист «reviews» и первую строку с названиями столбцов.
  - Не отключайте скрипт в «Развёртываниях» без нужды.


Если письма не приходят:
  - проверьте «Спам» и «Промоакции»;
  - убедитесь, что заходили и деплоили именно тот Gmail, куда ждёте письма;
  - напишите исполнителю — проверит ADMIN_EMAIL и URL.


================================================================================
ЧАСТЬ 2. ИНСТРУКЦИЯ ДЛЯ ИСПОЛНИТЕЛЯ
================================================================================
Время: 20–40 минут настройка + 10 минут созвон с заказчиком.


ПОДГОТОВКА
  - Код: beauty-salon/google-apps-script/Code.gs
  - Сайт: script.js → переменная WEB_APP_URL
  - Два аккаунта для своего теста: B = ты, A = «заказчик»


--------------------------------------------------------------------------------
ШАГ 1. Создай таблицу (под своим Google B)
--------------------------------------------------------------------------------
  1. https://drive.google.com → Создать → Google Таблицы → Пустая.
  2. Имя файла: «Atelier Claire — отзывы» (или имя клиента).
  3. Внизу клик по «Лист1» → Переименовать → reviews
  4. В ячейки A1:G1 впиши (по одной колонке):
       A1 id
       B1 created
       C1 name
       D1 rating
       E1 text
       F1 status
       G1 token
  5. Можно выделить первую строку и сделать «Жирный» — не обязательно.


--------------------------------------------------------------------------------
ШАГ 2. Вставь Apps Script
--------------------------------------------------------------------------------
  1. В таблице: Расширения → Apps Script.
  2. Удали весь код в Code.gs по умолчанию.
  3. Открой локальный файл Code.gs из проекта и вставь целиком.
  4. Найди блок CONFIG и заполни:
       ADMIN_EMAIL: "почта_заказчика@gmail.com"   // куда слать письма
       SHEET_NAME: "reviews"
       SITE_NAME: "Atelier Claire"                // для темы письма
  5. Дискетка / Ctrl+S — сохранить.
  6. Имя проекта сверху: reviews-moderation.


--------------------------------------------------------------------------------
ШАГ 3. (Необязательно) Черновой деплой от себя
--------------------------------------------------------------------------------
  Можно один раз нажать «Развернуть» от себя, чтобы проверить, что код
  без ошибок. НО письма тогда будут с ТВОЕГО ящика.
  Для сдачи клиенту всё равно нужен деплой от ЗАКАЗЧИКА (шаг 5).


--------------------------------------------------------------------------------
ШАГ 4. Передай таблицу заказчику
--------------------------------------------------------------------------------
  1. В таблице нажми «Настройки доступа».
  2. Сначала добавь Gmail заказчика как «Редактор» → Готово.
  3. Снова «Настройки доступа» → рядом с его именем / роль владельца:
       «Передать владение» → укажи его Gmail → Отправить.
  4. Напиши заказчику:
       «Примите владение таблицей в письме Google. Потом на 10 минут созвон —
        один раз нажмём Разрешить, письма пойдут с вашей почты.»
  5. Дождись, пока он примет владение (без этого финальный деплой от него
     может упираться в права).


--------------------------------------------------------------------------------
ШАГ 5. Созвон: деплой от имени заказчика
--------------------------------------------------------------------------------
  Заказчик сидит в своём Google, ты диктуешь / шаришь экран.

  1. Открыть таблицу → Расширения → Apps Script.
  2. Развернуть → Новое развёртывание.
  3. Тип: Веб-приложение.
  4. Описание: reviews
  5. Запуск от имени: От моего имени (заказчик!)
  6. Кто имеет доступ: Все
  7. Развернуть → пройти «Разрешить» (см. часть для заказчика, шаг 5).
  8. Скопировать URL веб-приложения → сохранить у себя.

  Если Google пишет, что нужна проверка / владелец:
  - убедись, что владение уже у заказчика;
  - скрипт открыт именно в его сессии браузера (не твой профиль Chrome).


--------------------------------------------------------------------------------
ШАГ 6. Подключи URL к сайту
--------------------------------------------------------------------------------
  1. Открой portfolio/beauty-salon/script.js
  2. Найди строку:
       const WEB_APP_URL = "...";
  3. Вставь URL заказчика, например:
       const WEB_APP_URL = "https://script.google.com/macros/s/AKfycb.../exec";
  4. Убери локальный адрес http://127.0.0.1:8790/
     (он показывает «подтвердить» прямо на сайте — это только имитация).
  5. Сохрани файлы, обнови сайт на хостинге / GitHub Pages.


--------------------------------------------------------------------------------
ШАГ 7. Полный тест
--------------------------------------------------------------------------------
  1. Открой сайт → Отзывы (лучше окно инкогнито).
  2. Отправь отзыв с именем «Тест» и оценкой 5.
  3. На почте ЗАКАЗЧИКА (A) — письмо.
  4. Проверь поле «От»: должен быть его аккаунт / связанный Google.
  5. Подтвердить → обновить отзывы на сайте → «Тест» виден.
  6. Второй отзыв → Отклонить → на сайте не появляется.
  7. В таблице reviews строка со status = approved / rejected.


--------------------------------------------------------------------------------
ШАГ 8. Сдача
--------------------------------------------------------------------------------
  Отправь заказчику коротко:
  - как приходят письма и что жать;
  - не удалять лист reviews и заголовки;
  - твой Gmail можешь оставить Редактором на 2 недели гарантии, потом убрать.

  Себе сохрани:
  - URL веб-приложения;
  - ссылку на таблицу;
  - ADMIN_EMAIL.

ЧАСТЬ 3. ТЕСТ «ДВА GMAIL» ПРЯМО СЕЙЧАС (чеклист)
================================================================================

[ ] 1. Chrome / профиль B (исполнитель): создать таблицу + заголовки + Code.gs
       ADMIN_EMAIL = адрес A
[ ] 2. Передать владение на A
[ ] 3. Профиль A (заказчик): принять владение
[ ] 4. Профиль A: Apps Script → Развернуть веб-приложение → Разрешить

Когда URL готов — вставь в script.js или пришли ассистенту.


================================================================================
ЧАСТЬ 4. ЧАСТЫЕ ПРОБЛЕМЫ
================================================================================

«На сайте снова ссылка подтвердить, а не письмо»
  → В WEB_APP_URL всё ещё localhost:8790. Нужен URL script.google.com.

«Письмо пришло, но От = мой ящик исполнителя»
  → Деплой сделан от исполнителя. Переделать развёртывание под заказчика.

«Не приходит письмо»
  → Спам; неверный ADMIN_EMAIL; не нажали Разрешить; неверный аккаунт в браузере.

«Ошибка при отправке с сайта»
  → URL без /exec или доступ веб-приложения не «Все»;
  → CORS: в Code.gs POST уже под text/plain — не меняй Content-Type на сайте.

«Отзыв подтвердил — на сайте нет»
  → Обновить страницу с очисткой кэша;
  → в таблице status должен быть approved;
  → GET списка идёт на тот же WEB_APP_URL.

«Заказчик боится “небезопасно”»
  → Это нормально для личного Apps Script без публикации в магазине Google.
  → Объясни: скрипт только в ЕГО таблице, письма только ему, код открытый.
